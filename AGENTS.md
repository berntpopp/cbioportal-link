# AGENTS.md — cbioportal-link

Guidance for agents and contributors working in this repository.

> `README.md` is the front door and follows the **GeneFoundry README Standard v1** (hard
> ceiling 200 lines, fixed section order, machine-checked by `scripts/check_readme.py`).
> Depth lives in `docs/`. Do not grow the README: relocate.

## What this is

`cbioportal-link` is a read-only MCP server over the public **cBioPortal web API**
(`https://api.cbioportal.org`, the host cBioPortal's `llms.txt` names for scripts and agents)
plus a bundled **Cancer Hotspots** v2 + 3D snapshot: somatic alteration frequency by cancer
type, studies, mutations, cancer types and hotspots. It is one backend in the GeneFoundry
`-link` fleet, federated behind `genefoundry-router` under the namespace **`cbioportal`**.
Scaffolding was lifted from `pgscatalog-link`. Tracking issue:
https://github.com/berntpopp/genefoundry-router/issues/348.

## Two planes (non-negotiable boundary)

- **Data plane** — `config.py`, `ratelimit.py`, `api/`, `service.py`, `hotspots.py`. Calls cBioPortal
  over async httpx, validates IDs, returns **plain dicts**, raises typed
  `cbioportal_link.exceptions` errors. Never builds envelopes.
- **MCP plane** — `mcp/`. `run_mcp_tool` (`mcp/envelope.py`) owns `success`/`_meta` and turns
  exceptions into **returned** `isError` envelopes (never raised to the client).

## Invariants

- **cBioPortal llms.txt policy.** Only `api.cbioportal.org`; small **filtered** requests (a
  gene, a study); **sequential** (one request in flight, `asyncio.Lock` in `api/client.py`);
  cached in-process keyed on `/api/info` `dbVersion`; exponential backoff on 429/5xx honouring
  `Retry-After`; never loop the API for bulk data (at most `MAX_STUDIES` = 10 studies a call).
- **Never exposed:** `molecular-data`, `copy-number-segments`, `clinical-data`, unfiltered
  `mutated-genes/fetch`, and any sample or patient identifier (mutations are aggregated per
  variant). Guarded by `tests/test_service.py`.
- **Honest denominators.** Frequency = samples altered / samples profiled for the gene
  (`mutation-data-counts/fetch`, panel-aware), per study; overlapping studies are never summed.
  `alteration-counts/fetch` is 404 in the Go rewrite: do not depend on it (live drift alarm in
  `tests/integration/`).
- **Licence on every row.** `shaping.licence()` reads the study description (CC code, else
  `ODbL-1.0`); NC/ND studies are `restricted` and excluded unless `include_restricted=true`.
- **Assembly labelled.** Coordinates carry `assembly` from the study's `referenceGenome`.
- **data_version** = `/api/info` portal + database version; each study row has `import_date`.
- **Hotspots snapshot** (`cbioportal_link/data/`, ODbL 1.0) is rebuilt only by
  `scripts/build_hotspots.py` from a pinned, sha256-verified genome-nexus-importer commit;
  never copy Cancer Hotspots (AGPL) code.
- **Untrusted text.** Study descriptions are fenced with `fence_untrusted_text`; upstream
  error bodies are only used to classify, never echoed (fixed messages in `api/client.py`).
- **Politeness.** The User-Agent names the product, version and project URL only.
- **6-code error taxonomy**: `invalid_input`, `not_found`, `ambiguous_query`, `rate_limited`,
  `upstream_unavailable`, `internal`.
- Tools publish no `outputSchema` (Tool-Surface Budget Rule 3); every input property has a
  description, required ones carry `examples`, closed vocabularies are `Literal` enums.
- Keep `mcp/capabilities.py::TOOLS` equal to the registered tool set and the README `## Tools`
  table in sync (both tested).

## Fleet deploy contract

`docker/docker-compose.npm.yml` (deployed by the fleet controller `strato_v6_docker_npm`)
declares `user: "10001:10001"` — this image's own uid:gid from `docker/Dockerfile`. `user` must
NOT appear in `docker/docker-compose.yml` / `docker/docker-compose.prod.yml` (the release gate
forbids it). Guard: `tests/unit/test_deploy_overlay_user.py`. Both reusable-workflow pins
(`container-ci.yml`, `container-release.yml`) track the same `genefoundry-router` revision.

Release checklist: bump `pyproject.toml`, `uv lock`, `CHANGELOG.md` heading
`## [x.y.z] - YYYY-MM-DD`, `CITATION.cff` `version:` (generated by the router's
`make citation-write`), tag `vx.y.z`, approve the `release` environment gate via
`gh api repos/berntpopp/cbioportal-link/actions/runs/<id>/pending_deployments` (it can gate more than
once). **Never `gh release create`** — the workflow creates the immutable release.

## Definition of done

`make ci-local` green: format-check, lint-ci, lint-loc (≤500 lines/file), lint-readme,
lint-surface, mypy `--strict`, tests. Unit tests are network-free: `respx` replays recorded
cBioPortal responses. Live checks are opt-in
(`make test-integration`, a handful of polite calls).

## Make targets

```
make install          # uv sync --group dev
make ci-local         # the definition-of-done gate
make test             # unit tests
make test-integration # live cBioPortal calls (opt-in, sequential)
make dev              # unified HTTP server on 127.0.0.1:8000
make mcp-serve        # stdio MCP server
make docker-up        # Docker stack; make docker-url prints the MCP URL
```

## Conventions

- Python 3.14, `uv`, hatchling; structlog to **stderr only** (stdout is the stdio protocol).
- TDD: failing test first. Files under 500 lines.
- `tests/conformance/` and `scripts/check_readme.py` / `scripts/surface.py` are vendored
  byte-identical from `genefoundry-router`; do not edit them here.

Research use only; not for clinical decision support and not a clinical actionability report.
cBioPortal data: ODbL 1.0 plus per-study terms; Cancer Hotspots: ODbL 1.0 (see NOTICE).
